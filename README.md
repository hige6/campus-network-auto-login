# 安徽大学校园网自动登录程序

针对使用 `172.16.253.3` Dr.COM 门户的校园网，提供账号配置界面、后台无窗口检测、开机自启和自动重连。默认账号后缀 `@cmccyx`，也可从界面选择其他页面列出的后缀。只实现从学校当前配置探测到的 Portal method=1。

## 使用

1. 下载本仓库文件，或通过 GitHub 的 **Code → Download ZIP** 下载并解压完整目录。
2. 双击 `login.cmd`。若启动器尚未构建，脚本会在本机编译它。
3. 在窗口填写学号和密码，选择账号后缀、是否开机自启，再点“保存并启用”。已有完整 `@后缀` 的账号不会再被追加。
4. 关闭配置窗口后，后台仍会运行。外网已通时跳过认证；断线后按学校 Portal 状态尝试重新认证。双击 `login.cmd` 可再次修改配置。
5. 双击 `uninstall.cmd` 停止后台进程、删除开机启动项及本机凭据。卸载不会注销当前网络会话。

无需管理员权限。密码用 Windows DPAPI 加密存储，只能由同一 Windows 用户在同一台电脑解密。公共仓库只放源代码与启动文件；凭据、运行状态和编译出的 exe 受 `.gitignore` 排除。

## 后台检测方式

脚本查询校园网 Dr.COM Portal 在线状态，并访问 Microsoft、Firefox 的公共联网检测地址，只有得到预期响应内容才确认外网可用。校园网接口显示在线而外网不通时分别报告；接口异常时不盲目重复认证。检测周期约一分钟。

公共联网检测只证明检测地址可达，不保证所有网站均可访问；VPN、多网卡可能影响检测结果。学校 Portal 使用 HTTP，账号密码沿用学校网页认证流程通过学校网络提交。请只在获准的校园网和自己的账号上使用。

## 本地构建

在 Windows PowerShell 5.1 运行：

```powershell
.\build.ps1
```

这会使用系统内置 C# 编译工具生成 Windows 图形子系统启动器，不需要安装第三方依赖。


## 可选：外网失败时只关闭 Wi-Fi

在设置窗口勾选“认证失败或外网不通时关闭 Wi-Fi（不会自动打开）”，再点“保存并启用”。认证尝试失败，或已认证但外网仍不通时，再检查一次外网；仍不通则关闭 Windows 的 Wi-Fi 开关，约一分钟后继续检测有线宽带。每次启用最多尝试关闭一次。没有勾选时不触发。

此选项用于 Wi-Fi 干扰有线宽带的情况，请先接好网线。程序不会自动打开 Wi-Fi，也不会重新连接无线网络；取消勾选、卸载后同样不会自动恢复。需要无线网络时在 Windows 设置中手动打开。若系统不允许控制开关，会显示失败原因。具体操作使用 [Windows 无线开关 API](https://learn.microsoft.com/en-us/uwp/api/windows.devices.radios.radio.setstateasync)，会检查最终状态。

此更新通过了模拟触发条件、重复关闭保护、权限拒绝处理，以及后台启动和卸载测试；仅在本机读取了真实 Wi-Fi 开关状态，未实际执行关 Wi-Fi 测试。
